# Jonathan Barbeau – PowerShell Resume CLI

Welcome to my interactive resume – delivered through a PowerShell module, because sometimes a PDF just isn’t enough. If you’re here, you're probably interested in my background in cybersecurity, systems engineering, or just enjoy creative CLI wizardry.

This repo lets you explore my resume in a terminal-based interface using real PowerShell commands.

---

## 💻 How to Use

```powershell
git clone https://github.com/JonathanEBarbeau/resume.git
cd resume
Import-Module ./JonathanBarbeau.psm1
Show-JonathanResume
